# State experiments

For money, stock, accounts, backup and shared stores. Load Cleanup's `../../../code-cleanup-helper/references/topics/state-integrity-audit.md`. Repairs use existing authority; no production data or publishing implied.

- `rd.state.real-chain`: freeze UI -> adapter -> commit -> reply -> UI -> restart claims. Use isolated stores and production adapters, preload, IPC and authenticated transport. Pure validators or counts cannot prove delivered journeys.
- `rd.state.adversarial-replay`: persist original ID before mutation. Pair valid calls with precommit rejection, postcommit reply loss/restart, same-ID changed input, stale stock/store identity, quota, forged frame/actor and late rollback. Compare complete stock, money, points, cart, ledger and backup; include historical rows beyond UI limits and cumulative partial/full refunds.
- `rd.state.learning-transfer`: generalized positive/negative replay plus real target regressions; typed immutable experiment, reciprocal sanitized receipt, one owner and prior links preserved through rebuild. Raw logs, paths and metrics remain project-local; no measured scope may certify deployed services or physical devices.

Shared store: one authority, no offline local replica; parallel last stock, native invalidation, expiry/revocation, replacement identity, existing-tab fragment re-pair, pagehide/pageshow and changed network address. Inventory receiving atomically binds stock, purchase, catalogue and receipt; stale edits reconcile. Unreadable historical receipts stay uncertain.

Money/history: original-shift prepaid cash excludes gifts; retain zero settings, account identities, historical timestamps and tied-row ordering. Unstarted cancellation releases resources; consumed cancellation keeps loss/capacity. Freeze unit costs, split actual tenders and preserve committed evidence.

Caller controls: fractional/integer units, invalid precision/sign/stock, pending quick-action double clicks and original-ID recovery finishing the original form. Local midnight/month filters match ledger dates; parse timestamp instants and reject reversed periods. Verify injected clocks in the final page and resized touch geometry. Fixed child program/literal data, contextual escaping, real exit/marker and exact delivered bytes precede fresh/restart/previous-version claims.

Detailed probes: [state families](../state-integrity-probes.md). Use when planning a family; no device, provider, trusted updater or public-release inference.
